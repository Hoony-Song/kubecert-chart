# Kubecert Chart

This chart deploys the Kubecert exam platform application workloads and the Helm-managed contracts around them. It does not contain private application source, private keys, kubeconfigs, Runtime Node images, or real secret values.

## Required Runtime Values

Real deployments must provide image repositories and immutable tags or digests generated by the private `kubecert` release tooling:

- `images.api.repository`
- `images.api.tag` or `images.api.digest`
- `images.worker.repository`
- `images.worker.tag` or `images.worker.digest`
- `images.terminalGateway.repository`
- `images.terminalGateway.tag` or `images.terminalGateway.digest`
- `images.examWeb.repository`
- `images.examWeb.tag` or `images.examWeb.digest`
- `images.adminWeb.repository`
- `images.adminWeb.tag` or `images.adminWeb.digest`

The default `values.yaml` intentionally leaves those empty.

## Dependency Modes

PostgreSQL, Redis, and KEDA are modeled with bundled and external modes. The first migration renders the application workload contract; dependency chart packaging is normalized by the follow-up dependency task.

## Secrets

Use existing Secrets for real deployments, or enable chart-created Secrets only from private local values files.

Do not commit real passwords, SSH keys, JWT secrets, token values, or kubeconfig content.
