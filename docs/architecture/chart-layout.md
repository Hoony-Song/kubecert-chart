# Chart Layout

`kubecert-chart` is the public Helm chart repository.

## Responsibilities

- Own public chart source under `charts/kubecert`.
- Provide placeholder-based example values.
- Package and publish chart releases.
- Document install, upgrade, and external dependency modes.

## Non-Responsibilities

- It does not contain private application source code.
- It does not contain question-bank source content.
- It does not contain real secret values or SSH keys.
- It does not install Runtime Node operating systems.
